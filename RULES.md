# Project Rules

## Storybloq Completion Workflow

When completing a Storybloq ticket or issue, do not stop at local edits. Before handoff:

- Include every relevant change in the final commit, including `.story/` ticket or issue status transitions.
- Commit the implementation and Storybloq transition together so the repository and project tracker stay consistent.
- Push the branch and open a GitHub pull request / merge request for review.
- In the final note, include the commit hash and pull request / merge request link.
